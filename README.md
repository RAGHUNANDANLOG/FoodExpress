# FoodExpress

FoodExpress is a React app built with Vite and styled with Tailwind CSS.

## Getting started

Install dependencies and start the local development server:

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the Vite development server.
- `npm run build` creates a production build in `dist`.
- `npm run preview` serves the production build locally.
- `npm run lint` runs Oxlint.

Tailwind CSS is integrated through the Vite plugin. Add styles with Tailwind
utility classes in JSX; global styles live in `src/index.css`.
